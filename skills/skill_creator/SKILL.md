# Dynamic Skill Creator
Whenever you learn a specialized library, API, or repeatable pattern for the project:
1. Create a dedicated skill directory: `skills/<skill_name>/`
2. Write a comprehensive manual: `skills/<skill_name>/SKILL.md`
3. Document required tools, config files, and usage steps.
